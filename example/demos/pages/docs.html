Webhooks

Webhooks tell your server when something happens in your workspace: a payment settles, a member joins, a file finishes processing.

Endpoints

Add an endpoint in Settings → Developers. Each endpoint picks the events it listens to, and gets its own signing secret.

Payloads

Every delivery is a POST with a JSON body. The type field names the event; data holds the object as it was when the event happened.

Verifying signatures

Check the signature header before trusting a payload. The SDK does it in one call:

import { verify } from "@northwind/sdk";

const event = verify(body, headers["x-northwind-signature"], secret);
if (event.type === "payment.settled") fulfil(event.data);

Reject anything older than five minutes to block replays.

Retries

Failed deliveries retry with backoff for three days.
