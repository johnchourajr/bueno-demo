Webhooks

Los webhooks avisan a tu servidor cuando hay una perturbación en la Fuerza: se completa un pago, se une un piloto, termina de procesarse un holograma.

Endpoints

Añade un endpoint en Ajustes → Desarrolladores. Cada endpoint elige los eventos que escucha y tiene su propio secreto de firma.

Cargas

Cada entrega es un POST con un cuerpo JSON. El campo type nombra el evento; data guarda el objeto tal como estaba cuando ocurrió.

Verificar firmas

Comprueba la cabecera de firma antes de confiar en una carga. El SDK lo hace en una llamada:

import { verify } from "@alianza/sdk";

const event = verify(body, headers["x-alianza-firma"], secret);
if (event.type === "planos.recibidos") atacar(event.data);

Rechaza lo que tenga más de cinco minutos para bloquear repeticiones. Podría ser una trampa.

Reintentos

Las entregas fallidas se reintentan con espera creciente durante tres días estándar.
